# 소음 방해지수(I) 측정기

첨부된 연구 노트(`벽을 통과한 저주파 소음의 실내 영향 예측 지표 I`)의 수식을 그대로 구현한
브라우저 기반 웹 앱입니다. 마이크로 주변 소음을 캡처하여 이산 푸리에 변환(DFT)을 수행하고,
벽 전달함수 $H(f)$와 인간 영향 가중 $w(f)$를 적용해 방해지수 $I$를 실시간으로 계산·표시하며,
측정값을 신고 기록으로 남길 수 있습니다.

## 실행 방법

마이크 접근(`getUserMedia`)은 보안 컨텍스트(HTTPS 또는 localhost)에서만 동작하므로,
로컬 정적 서버로 실행해야 합니다.

```bash
npx serve .
# 또는
python3 -m http.server 8000
```

브라우저에서 `http://localhost:<port>` 접속 후 "측정 시작" 버튼을 눌러 마이크 권한을 허용하세요.

## 수식 ↔ 코드 매핑

| 문서 | 코드 |
|------|------|
| $X_k = \sum_n x_n e^{-2\pi i kn/N}$ (2절, 3절) | `src/fft.js`의 `fft()` (radix-2 iterative FFT), `windowedDft()` |
| $H(f)$ 벽 전달함수 (4절) | `src/wallTransfer.js` |
| $w(f)$ 인간 영향 가중 (5절) | `src/weighting.js` (`aWeightingDb`, `aWeightingLinear`, `perceptualWeight`) |
| $I = \sum_k w(f_k)\,|H(f_k)X(f_k)|^2$ (2절) | `src/indexCalculator.js`의 `computeDisturbanceIndex()` |
| 소음 원인 추정 | `src/noiseClassifier.js` (지배 주파수 대역 기반 휴리스틱) |
| 마이크 캡처 · UI · 신고 기록 | `src/app.js`, `index.html`, `style.css` |

## 파라미터 ($f_c$, $f_0$, $\gamma$)

문서 6절에 따라 이 세 값은 실험/환경별로 결정되어야 하는 값이라, 하드코딩하지 않고
화면의 슬라이더로 실시간 조정할 수 있게 했습니다(기본값 `fc=200Hz`, `f0=200Hz`, `gamma=1.0`).
조정값은 `localStorage`에 저장되어 새로고침 후에도 유지됩니다.

## 화면에 보이는 값의 의미와 한계

- **I (raw)**: 문서의 정의를 그대로 계산한 값으로, 절대적인 dBA 같은 표준 단위가 아닙니다(문서 7절:
  "$I$는 성가심 자체가 아니라 성가심을 예측하기 위한 지표").
- **I(dB 환산)**, **체감 방해도 점수(0-100)**: raw $I$ 값은 사람이 직관적으로 읽기 어려워 로그 스케일
  변환과 0-100 매핑을 추가했습니다. 이 매핑의 기준점(`refDb`, `spanDb`, `src/indexCalculator.js`)은
  **아직 실험으로 보정되지 않은 임시값**입니다. 문서 8절의 검증 실험(동일 dBA·다른 $I$ 소리쌍 평가)을
  거쳐 조정해야 합니다.
- **추정 소음 원인**: 지배 주파수 대역만으로 분류하는 단순 휴리스틱입니다. 실제 음원 분리나 머신러닝
  기반 분류가 아니므로 참고용입니다.
- **마이크 측정값은 dB SPL로 보정(calibration)되지 않았습니다.** 기기/마이크마다 게인이 달라
  절대 음압레벨과 직접 비교할 수 없고, 동일 기기·동일 환경에서의 상대 비교 용도로 사용하세요.
- **"신고" 기능은 실제 지자체/기관 신고 시스템에 접수하지 않습니다.** 측정값을 기기 내 목록에
  기록하고 CSV로 내보낼 수 있게만 구현했습니다(연동할 실제 신고 API가 제공되지 않았기 때문입니다).
  실제 기관 접수 연동이 필요하면 해당 기관의 API 사양을 알려주시면 추가하겠습니다.

## 테스트

핵심 수식(FFT, A-weighting, 벽 전달함수, 지표 계산)은 Node 내장 테스트 러너로 검증했습니다
(합성 사인파의 지배 주파수 검출, $f_0$ 경계 연속성, $H(f)$ 감쇠 등).

```bash
npm test
```

마이크 캡처/UI 부분은 실제 브라우저와 마이크 입력이 필요해 이 환경에서 자동 테스트하지 못했습니다.
로컬 서버로 실행 후 브라우저에서 직접 확인해 주세요.
